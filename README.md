# Интернет-магазин — «Цветочный Рай» (`daten23`)

## Назначение проекта

Репозиторий `daten23` представляет собой проект статического интернет-магазина.

- В основной ветке `main` на текущий момент размещена только базовая заготовка репозитория (лицензия и README-файл без исходного кода).
- В неслитой ветке разработки `claude/flower-shop-website-T3FN3` реализован полноценный фронтенд-прототип сайта цветочного магазина **«Цветочный Рай»** («Магазин свежих цветов») с витриной букетов, каталогом товаров, интерактивной корзиной на `localStorage` и страницей контактов с формой обратной связи.

---

## Архитектура и основные компоненты

### Ветка `main`
Содержит только файл лицензии (`LICENSE`) и документацию (`README.md`); прикладной код в `main` пока отсутствует.

### Ветка `claude/flower-shop-website-T3FN3`
Многостраничное клиентское веб-приложение без серверной части (Static Frontend):

1. **Главная страница (`index.html`)**
   - Верхняя навигационная панель (`.navbar`) со ссылками на разделы («Главная», «Каталог», «Контакты») и индикатором количества товаров в корзине (`#cartCount`).
   - Главный промо-экран (`.hero`) с кнопкой перехода к каталогу.
   - Блок преимуществ (`.features`): свежие цветы, быстрая доставка (2–4 часа), индивидуальный подход, гарантия качества.
   - Витрина популярных букетов (`.popular-products`): 3 карточки товаров («Букет из роз» — 2500 ₽, «Весенние тюльпаны» — 1800 ₽, «Солнечные подсолнухи» — 2000 ₽) с кнопками добавления в корзину.
   - Подвал сайта (`footer`) с контактными данными и режимом работы (`Пн-Вс: 8:00 - 22:00`), а также модальное окно корзины (`#cartModal`).

2. **Страница каталога (`catalog.html`)**
   - Заголовок каталога (`.catalog-hero`) и сетка из 12 товарных позиций букетов и композиций (в диапазоне от 1500 ₽ до 9500 ₽: «Букет из роз», «Весенние тюльпаны», «Солнечные подсолнухи», «Пионы премиум», «Экзотический микс», «Нежность», «Полевые цветы», «Винтажный шарм», «Сакура», «Зеленая свежесть», «101 роза», «Лаванда»).
   - Каждая карточка содержит кнопку `.add-to-cart` с атрибутами `data-name` и `data-price`.

3. **Страница контактов (`contact.html`)**
   - Блок контактной информации: адрес (г. Москва, ул. Цветочная, д. 15, м. «Парк Культуры»), телефоны, email (`info@flowerparadise.ru`, `orders@flowerparadise.ru`), график работы и ссылки на соцсети.
   - Форма обратной связи (`#contactForm`) с полями: имя (`#name`, обязательное), email (`#email`, обязательное), телефон (`#phone`) и сообщение (`#message`, обязательное).
   - Секция карты (`.map-container` / `.map-placeholder`).
   - Встроенные CSS-стили (`<style>`), включая адаптивную сетку для экранов до `768px`.

4. **Клиентская логика (`script.js`)**
   - Состояние корзины хранится в браузере через `localStorage` (ключ `'cart'`).
   - Реализованы функции `addToCart(name, price)`, `removeFromCart(index)`, `saveCart()`, `updateCartCount()`, `displayCart()`.
   - Управление модальным окном корзины (`#cartModal`, `#cartLink`, `.close`) и оформление заказа (`#checkoutBtn`) с отображением итоговой суммы через `alert()` и очисткой корзины.
   - Клиентская обработка отправки формы `#contactForm` с выводом подтверждения через `alert()` и сбросом полей (`contactForm.reset()`).

5. **Таблица стилей (`style.css`)**
   - Общие стили оформления макета, карточек товаров, навигации, модального окна и подвала, подключаемые на всех трёх страницах сайта.

## Установка и запуск

В ветке `main` исполняемый или отображаемый код веб-приложения пока отсутствует.

Чтобы просмотреть прототип сайта из ветки `claude/flower-shop-website-T3FN3`:

1. Клонируйте репозиторий и переключитесь на ветку разработки:
   ```bash
   git clone https://github.com/svend4/daten23.git
   cd daten23
   git checkout claude/flower-shop-website-T3FN3
   ```
2. Откройте файл `index.html` в любом современном браузере (сборка и установка зависимостей не требуются) либо запустите любой локальный статический веб-сервер в корне каталога.
